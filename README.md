# SFP/SFGP Archive Parser

[![Python](https://img.shields.io/badge/python-3.10%2B-blue)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

Парсер и распаковщик проприетарных бинарных архивов Alawar Stargaze. Формат восстановлен методом реверс-инжиниринга (Ghidra + анализ дампов памяти).

Проект умеет:
- определять формат архива автоматически по магии;
- парсить заголовок и таблицу записей;
- извлекать файлы с сохранением структуры подпапок;
- работать как CLI-утилита и как библиотека.

## Формат

Архивы состоят из **заголовка**, **таблицы записей** и **блока данных**.

### Header (12 байт)

| Смещение | Размер | Тип    | Поле           | Описание                              |
|----------|--------|--------|----------------|---------------------------------------|
| `0x00`   | 4      | magic  | `MAGIC`        | `53 46 50 01` (SFP) или `53 46 47 50` (SFGP) |
| `0x04`   | 2      | `u16`  | `files_count`  | Количество записей                    |
| `0x06`   | 2      | —      | `padding`      | Выравнивание                          |
| `0x08`   | 4      | `u32`  | `archive_size` | Полный размер архива в байтах         |

### Entry (128 байт на запись)

| Смещение | Размер | Тип     | Поле       | Описание                                  |
|----------|--------|---------|------------|-------------------------------------------|
| `0x00`   | 2      | `u16`   | `name_len` | Длина имени в байтах (без `\0`)           |
| `0x02`   | 2      | `u16`   | `type`     | Тип записи (например, `0x58`, `0x70`)     |
| `0x04`   | 2      | `u16`   | `hash`     | hash имени (см. ниже)                     |
| `0x06`   | 2      | —       | `padding`  | Выравнивание                              |
| `0x08`   | 112    | `char[]`| `name`     | Имя файла (C-строка, до `\0`)             |
| `0x78`   | 4      | `u32`   | `file_size`| Размер данных                             |
| `0x7C`   | 4      | `u32`   | `offset`   | Смещение данных относительно начала mapping |

Все многобайтовые поля — **little-endian**.

В поле `hash` лежит 16-битная контрольная сумма имени. Реализация — в `hash.py` (используется для верификации записей).

## Установка

Требуется Python 3.10+.

```bash
git clone https://github.com/psomic/Alawar-Stargaze-unpacker.git
cd Alawar-Stargaze-unpacker
```

Зависимостей нет — только стандартная библиотека.

## Использование

### CLI

Показать поддерживаемые форматы:

```bash
python unpacker.py --list-formats
```

```
Известные форматы:
  53465001   SFP        header=12 entry=128
  53464750   SFGP       header=12 entry=128
```

Вывести содержимое архива:

```bash
python unpacker.py game.pack
```

```
=== game.pack ===
Формат:        SFP (53465001)
files_count:   18
archive_size:  0x1A2B40 (1715008)
entries:       18

Entry(name='fonts/basefont.xml', type=0x0070, hash=0x00BF, size=4096, offset=0x1000, name_len=18)
Entry(name='fonts/bigfont.xml',  type=0x0070, hash=0x11A3, size=8192, offset=0x2000, name_len=17)
...
```

Распаковать в папку:

```bash
python unpacker.py game.pack extracted/
```

```
[+] fonts/basefont.xml -> extracted/fonts/basefont.xml (4096 байт)
[+] fonts/bigfont.xml  -> extracted/fonts/bigfont.xml  (8192 байт)
...
```

### Как библиотека

```python
from pathlib import Path
from unpacker import parse_archive, extract_files

data = Path("game.pack").read_bytes()
fmt, header, entries = parse_archive(data)

print(f"Формат: {fmt.name}, файлов: {header.files_count}")

for e in entries:
    print(e.name, e.file_size, hex(e.offset))

extract_files(data, entries, "extracted/")
```

## Протестированные игры

Распаковщик проверен на реальных архивах следующих игр (Alawar Stargaze):

- **Масяня в полной Африке**
- **Таинственный парк. Разбитая пластинка**
- **Гиблые земли. Город теней**
- **Игры со смертью: Возмездие**
- **Ангелы тьмы. Маскарад теней**

Во всех случаях:
- архив определяется автоматически по магии (`SFP` или `SFGP`);
- `files_count` и `archive_size` совпадают с реальными значениями;
- все записи извлекаются без ошибок `offset`/`file_size`;
- структура подпапок внутри архива сохраняется при распаковке;
- имена файлов читаются корректно.

## Как это делалось

1. Дампы памяти и файлов игр анализировались в **Ghidra**: найдены функции чтения заголовка и записей, восстановлены структуры (`Header`, `Entry`).
2. Алгоритм hash-функции восстановлен из декомпиляции.
